# 🌟 منصة نجوم التعلم
### منصة تعليمية تفاعلية لتلاميذ السنة الأولى متوسط

---

## 🗂️ هيكل المشروع

```
educational_platform/
├── app/
│   ├── __init__.py          ← App factory + extensions
│   ├── models.py            ← كل نماذج قاعدة البيانات
│   ├── auth/                ← تسجيل الدخول والخروج والتسجيل
│   │   ├── __init__.py
│   │   └── routes.py
│   ├── admin/               ← لوحة تحكم المشرف (CRUD كامل)
│   │   ├── __init__.py
│   │   └── routes.py
│   ├── student/             ← واجهة الطالب
│   │   ├── __init__.py
│   │   └── routes.py
│   └── static/
│       ├── css/style.css    ← نظام التصميم الكامل
│       ├── js/main.js       ← التفاعلية
│       └── uploads/         ← الصور المرفوعة
├── templates/
│   ├── base.html            ← القالب الأساسي
│   ├── auth/                ← صفحات تسجيل الدخول
│   ├── admin/               ← قوالب لوحة التحكم
│   └── student/             ← قوالب الطالب
├── config.py                ← إعدادات التطبيق
├── run.py                   ← نقطة الدخول
├── seed.py                  ← بيانات تجريبية
└── requirements.txt
```

---

## 🚀 خطوات التشغيل

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. إعداد ملف البيئة
```bash
cp .env.example .env
```

### 3. تشغيل التطبيق مباشرة
```bash
python run.py
```
> سيتم إنشاء قاعدة البيانات تلقائياً عند أول تشغيل.

### 4. (اختياري) تعبئة بيانات تجريبية
```bash
python seed.py
```

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| Flask 3 | إطار العمل الأساسي |
| SQLAlchemy | ORM قاعدة البيانات |
| Flask-Login | إدارة الجلسات |
| Flask-WTF | حماية CSRF |
| Flask-Migrate | ترحيل قاعدة البيانات |
| Jinja2 | محرك القوالب |
| SQLite | قاعدة البيانات (dev) |
| Cairo Font | الخط العربي |
| Font Awesome | الأيقونات |
